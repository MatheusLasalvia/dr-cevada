# Dr. Cevada — Cardápio digital

## Estrutura
- `index.html`: estrutura da página.
- `css/styles.css`: estilos e responsividade.
- `js/menu.js`: produtos, imagens, renderização, botões e navegação.
- `assets/images/`: logo, fotos dos produtos e imagem do rodapé.

## Como executar
Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Como trocar fotos
Substitua o arquivo correspondente em `assets/images/`, mantendo o mesmo nome e extensão. Para adicionar uma foto nova, coloque-a nessa pasta e atualize o caminho no objeto `IMG` em `js/menu.js`.

## Como editar produtos e preços
Edite os arrays `P1`, `P2` e `D` no início de `js/menu.js`. Os preços usam vírgula decimal, por exemplo `15,00`.
